# Imagens

Os arquivos PNG usados no README são gerados automaticamente ao executar o notebook:

```bash
jupyter notebook notebooks/01_data_exploration.ipynb
```

Arquivos esperados:

- `class_distribution.png`
- `confusion_matrix_logistic_regression.png`
- `confusion_matrix_random_forest.png`
- `precision_recall_curve.png`
- `feature_importance.png`

Após gerar, faça commit destes PNGs para o GitHub (a interface de upload do GitHub ou `git add images/*.png`).
