# Imagens do projeto

Os gráficos PNG detalhados (matrizes de confusão, curva Precision-Recall, etc.) são gerados ao executar o notebook `notebooks/01_data_exploration.ipynb`.

Os arquivos SVG nesta pasta servem como visualização leve no README do GitHub.

Para gerar os PNGs localmente:

1. Coloque `orders.csv` em `data/`
2. Execute o notebook completo
3. Salve as figuras geradas nesta pasta com os nomes referenciados no README principal
